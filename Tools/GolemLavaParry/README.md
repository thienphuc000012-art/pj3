# GolemLava Attack4 parry

`Assets/Adventure/Prefabs/Enemy/GolemLava/ActionData/attack4.asset` is a ranged `SpawnAtTarget` skill (`Is Melee` is off). Its controller state uses `Anim/attack4.anim`.

The clip had `AnimEvent_PlayVFX` and `AnimEvent_DealDamage` at 1.00 seconds, plus `AnimEvent_EndAttack` at 1.6333333 seconds, but no event to open a parry window. `Use Vfx Parry` automatically times Shoot/Beam attacks; this SpawnAtTarget action uses animation-event timing.

The fix adds **`AnimEvent_OpenParry` at 0.70 seconds**, giving a 0.30-second window before the hit. The existing VFX, damage and end times, action settings, animation curves and controller are preserved. DealDamage automatically closes/resets parry state, so a separate closing event is unnecessary for this single-hit clip.

To adjust difficulty, move the OpenParry event in `GolemLava/Anim/attack4.anim` while keeping it before the DealDamage event. Press Space in the 0.70–1.00 second window during the Enemy's animation.

The timestamped `Before-*` folder contains the original clip and ActionData. `Validation.txt` is generated by **Tools > Adventure > Combat > Validate GolemLava Attack4 Parry**. This checks the controller/clip binding, actual event timing, early/correct/late parry outcomes through the real combat/parry code, HP damage/reset, and the GolemLava receiver on the currently loaded combattest scene. It runs in an isolated Edit Mode preview without starting gameplay or writing campaign saves/live scenes.
